# UAT Scenarios (Business Acceptance): 014-composite-booking

---

## UAT-001: Сантехник принимает комплексный заказ «смеситель + фильтр в один час»

- **Target Persona**: `OWNER` (владелец мастерской) + `OPERATOR`
- **Business Goal**: клиент записывается на «замену смесителя с установкой фильтра за один выезд», система сама считает время и деньги; мастер видит состав работ в Telegram.
- **Success Criteria**:
  1. Клиент на `/book` видит чекбоксы доп-услуг с итогом «60 мин · 100 USD» без ручного пересчёта.
  2. В Telegram-карточке — обе позиции, длительность контейнера, сумма.
  3. Двойная броня не даёт наложить вторую корзину на тот же интервал.
- **Validation Steps**: оформить комплекс → проверить карточку → попытаться занять пересекающийся слот вторым клиентом → получить честный 409/отсутствие слота.
- **Business Sign-off**: [PENDING]

## UAT-002: «Туалет — следующим слотом» и депозит по корзине

- **Target Persona**: `OWNER` + клиент
- **Business Goal**: расширение визита отдельным слотом оформляется второй бронью того же клиента; предоплата депозита считается по всем позициям контейнера и возвращается целиком по правилу основной работы.
- **Success Criteria**:
  1. Вторая бронь на соседний слот создаётся независимо; обе видны в approvals.
  2. DEPOSIT-корзина из двух позиций требует один платёж Σ депозитов.
  3. Отмена до cutoff primary возвращает всю сумму депозита одной транзакцией.
- **Validation Steps**: оформить вторую бронь → оплатить DEPOSIT-корзину → отменить до cutoff → проверить refund.

# Ручные Тест-Кейсы Telegram Ботов — Client Bot & Staff Bot

> **Для кого:** QA-инженеры, которые проверяют Telegram-боты вручную (сообщения, кнопки, команды).
> **Как использовать:** После настройки webhooks (см. `manual-qa.md`) отправьте команды боту и проверьте сообщения в Telegram.

---

## Предварительные Условия (для всех ботов)

1. **Webhooks настроены:**
   ```bash
   bash specs/002-service-cart-and-staff-bot/checklists/scripts/_setup-webhooks.sh
   ```
   (если не запущено ранее)

2. **Оба бота зарегистрированы в BotFather:**
   - `TELEGRAM_BOT_TOKEN` (client bot) в `.env`
   - `STAFF_BOT_TOKEN` (staff bot) в `.env`

3. **Публичный URL для webhooks:**
   - Cloudflared tunnel запущен: `cloudflared tunnel --url http://localhost:3000`
   - Или ngrok: `ngrok http 3000`

4. **Переменные окружения:**
   ```bash
   export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."  # от BotFather
   export STAFF_BOT_TOKEN="654321:XYZ-UVW..."    # от BotFather
   export STAFF_CHAT_ID="<ваш_telegram_id>"      # где получать сообщения мастеру
   export PUBLIC_URL="https://xxx.trycloudflare.com"  # из cloudflared
   ```

5. **Сервер запущен:**
   ```bash
   npm run dev
   ```

## TC-BOT-CLIENT-01: /start Команда — Приветствие и Основные Кнопки

**Что проверяем:** Client Bot отправляет правильное приветственное сообщение с кнопками при /start.

### Шаг 1: Открыть Telegram и найти бота
```
Действие:   
  1. Открыть Telegram (мобильный или Desktop версия)
  2. Найти бота по ссылке (или добавить в контакты по имени)
  3. Кликнуть "Start" или ввести /start
Ожидаем:    
  ✓ Bot отправляет сообщение с текстом типа:
    "👋 Добро пожаловать в UnDreseller! 
     Выберите услугу, забронируйте слот и подтвердите заказ.
     [Кнопки ниже]"
  ✓ Видны inline-кнопки:
    - "📅 Browse Services" (или "Услуги")
    - "📋 My Orders" (или "Мои заказы")
    - "❓ Help" (или "Помощь")
```

**Проверочный список:**
- [ ] Bot ответил (не молчит)
- [ ] Сообщение содержит приветствие
- [ ] Видны минимум 2-3 кнопки
- [ ] Кнопки имеют эмодзи или текстовый индекс

---

### Шаг 2: Проверить форматирование сообщения
```
Действие:   Посмотреть на сообщение бота
Ожидаем:    
  ✓ Сообщение читаемо (шрифт обычный, не слишком мелкий)
  ✓ Нет бессмысленных символов или HTML-тегов (типа <b>, &quot;)
  ✓ Эмодзи отображаются корректно (не как квадраты)
  ✓ Линеbreak'и правильно расставлены (не всё в одну строку)
```

**Проверочный список:**
- [ ] Сообщение хорошо отформатировано
- [ ] Нет HTML/Markdown артефактов в Telegram
- [ ] Эмодзи видны

---

### Шаг 3: Нажать кнопку "Browse Services" (если есть)
```
Действие:   Нажать кнопку просмотра услуг
Ожидаем:    
  ✓ Bot отправляет список услуг или ссылку на веб-приложение:
    "Выберите услугу:
     🔵 express-code-review (30 мин, $100)
     🔵 standard-code-review (60 мин, $150)
     ... (остальные услуги)"
  ✓ Или кнопка открывает Web App (Telegram Mini App):
    "Tap to open app" с встроенным браузером
```

**Проверочный список:**
- [ ] Bot ответил на нажатие кнопки
- [ ] Услуги отображаются или открывается Web App

## Особенности для QA

### Где Искать Проблемы:
- **Console Telegram:** Обычно молчит, но если есть JS-ошибки в Web App — будут видны
- **Логи Сервера:** `npm run dev` покажет webhook-запросы от Telegram
- **Логи Базы:** Проверить статусы заказов через скрипты или DB клиент
- **Баланс Stars:** В Telegram профиле видно текущее количество Stars

### Как Воспроизвести:
1. Каждый тест можно запустить несколько раз (заказы не дублируются, создаются новые)
2. Использовать разные аккаунты/чаты для мастера и клиента
3. Cloudflared/ngrok держать активным на протяжении всего тестирования

### Когда Тестирование Завершено:
- [ ] Все TC-BOT-* тесты пройдены в обоих ботах
- [ ] Статусы заказов совпадают с ожиданиями
- [ ] Клиент и мастер получают правильные уведомления
- [ ] Кнопки не путают заказы
- [ ] Маскировка номера работает

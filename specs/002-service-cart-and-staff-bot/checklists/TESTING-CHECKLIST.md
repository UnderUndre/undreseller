## 🔍 Этап 4: Проверка Статусов в Базе Данных

Для каждого заказа проверить состояние в PostgreSQL:

```sql
SELECT 
  id, 
  status, 
  "createdAt", 
  "slotStart",
  "customerPhone",
  "customerName"
FROM "Order"
ORDER BY "createdAt" DESC
LIMIT 20;
```

- [ ] Все заказы имеют статусы из предусмотренного списка:
  - STAFF_PENDING
  - STAFF_CONFIRMED
  - STAFF_DECLINED
  - CLIENT_CONFIRMED
  - CLIENT_CANCELLED
  - COMPLETED
  - AUTO_CANCELLED_NO_CONFIRMATION

- [ ] Нет заказов с NULL статусом

- [ ] Слоты не перекрываются (два заказа на одно время):
  ```sql
  SELECT id, "slotStart", "slotEnd", status
  FROM "Order"
  WHERE status NOT IN ('STAFF_DECLINED', 'CLIENT_CANCELLED', 'AUTO_CANCELLED_NO_CONFIRMATION')
  ORDER BY "slotStart";
  ```
  Все слоты должны быть не пересекаются.

## 📊 Этап 5: Итоговая Проверка Консистентности

- [ ] **Корзина синхронизирована между браузером и сервером**
  - Add → POST /api/cart (200)
  - Delete → DELETE /api/cart/[itemId] (200)
  - Список → GET /api/cart (200, возвращает текущие товары)

- [ ] **Слоты не оверселл**
  - Один слот = одна бронь
  - Второй клиент на тот же слот = 409 SLOT_UNAVAILABLE

- [ ] **Заказы создаются корректно**
  - Все поля заполнены (name, phone, notes, serviceId, slotStart, slotEnd)
  - Цена совпадает с сервисом
  - Статус сразу = STAFF_PENDING или STAFF_CONFIRMED (зависит от реализации)

- [ ] **Уведомления ботов посылаются**
  - Client Bot: приветствие, уведомление о подтверждении мастером, просьба подтвердить
  - Staff Bot: карточка при создании, обновление при действии клиента

- [ ] **Обработчики ошибок работают**
  - Guard ошибки возвращаются с правильным кодом (DUPLICATE_CART_ITEM, SLOT_UNAVAILABLE, etc.)
  - HTTP статусы правильные (400, 409, 500 где нужно)
  - UI показывает ошибки пользователю (не молчит)

#### Дефект: DUPLICATE_CART_ITEM возвращает 200 вместо 400
```
Статус:     Открыт
Серьёзность: 🟠 High

Тест:       TC-WEB-05
Шаг:        Попытка добавить дубликат сервиса в корзину
Ожидаемо:   HTTP 400, error = "DUPLICATE_CART_ITEM"
Фактически: HTTP 200, сервис добавлен (дубликат разрешён)

Воспроизведение:
  1. Добавить express-code-review в корзину
  2. Из Console: fetch('/api/cart', ...) с тем же serviceId
  3. Response: 200 OK (вместо 400)

Логи:
  - Console: нет ошибок
  - Network: POST /api/cart → 200

Причина:    Проверка на дубликат не реализована в cart.ts
Фикс:       Добавить guard в POST /api/cart
```

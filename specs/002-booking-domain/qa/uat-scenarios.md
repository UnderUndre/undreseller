# UAT Scenarios: 002-booking-domain

## UAT-001: Владелец настраивает запись (day-0+)
1. Войти OWNER → создать bookable-услугу (45 мин, буферы) → задать WeeklyHours → поставить AvailabilityException (отпуск).
2. Открыть `/book` → увидеть слоты по сетке → забронировать тестом.
3. **Ожидание**: слоты соответствуют часам/буферам; бронь видна в админке; cancel-ссылка выдана.

## UAT-002: Оператор обрабатывает OUT_CALL заявку
1. Клиент бронирует OUT_CALL услугу → PENDING_APPROVAL.
2. OPERATOR (app-API) видит заявку → approve → клиентская бронь CONFIRMED; reject → слот освобождён.
3. **Ожидание**: PERFORMER не имеет доступа; CAS защищает от двойной обработки.

## UAT-003: Гонка за популярный слот
1. Две вкладки, один слот → обе жмут «забронировать».
2. **Ожидание**: одна — успех, вторая — 409 с человекочитаемым сообщением и авто-refresh грида.
